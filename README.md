# Student Management System

A comprehensive Student Management System built with Python and Tkinter, enabling user-friendly management of student data including adding, viewing, updating, and deleting student records.

## Features
- **Admin Access**: Admin can access the system upon entering correct username and password.
- **Database Connection**: Connect with the database of the pc with the system upon entering correct credentials.
- **Add New Student**: Add new student details including ID, Name, Mobile Number, Email, Address, Gender, Date of Birth, Added Date, and Added Time.
- **Show Data**: Display all student records in a tabular format with scrollable views.
- **Update Data**: Update the information of existing students.
- **Delete Data**: Remove student records from the system.
- **Export Data**: Exports student records from the system to csv excel file on pc.
- **Exit**: Exit from the window.
- **Responsive GUI**: A user-friendly interface built using Tkinter and various libraries like messagebox, ttk, filedialog, ttkthemes.
- **Validation**: Basic validation to ensure data integrity, such as limiting phone numbers to 10 characters.

## Files

- `sms.py`: Contains the main application logic for managing students.
- `login.py`: Handles user authentication.
